# Data_cleaning
End-to-end data cleaning &amp; analysis of an e-commerce dataset (orders, products, customers, sellers, reviews) using Python , Pandas &amp; SQL

## Project Overview
This project cleans and analyzes a multi-table e-commerce dataset 
(orders, products, customers, sellers, reviews) using Python and Pandas.

## Problem
Raw data had quality issues: negative prices, invalid ratings, 
inconsistent datetime formats, duplicates, and missing values.

## What I Did
- Data quality checks across all 5 tables
- Fixed invalid prices and ratings
- Converted datetime columns
- Handled nulls and duplicates
- Merged tables for analysis

## Tools
Python, Pandas, NumPy, Jupyter Notebook
